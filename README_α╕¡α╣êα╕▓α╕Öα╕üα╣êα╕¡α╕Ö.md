# DrawNote — DN-5011 Stable (รองรับออฟไลน์)

## มี 2 แบบในชุดนี้

### 1) web_PWA/ — ขึ้นเว็บ (Vercel) + ติดตั้งเป็นแอป
- อัปโหลด **ทุกไฟล์ในโฟลเดอร์ web_PWA รวมโฟลเดอร์ lib/** ขึ้น GitHub repo แล้ว Deploy บน Vercel (Framework: Other)
- เปิดเว็บครั้งแรกตอนมีเน็ต 1 ครั้ง → แอปเก็บทุกอย่างไว้ในเครื่อง (ตัวแอป + เครื่องมือ PDF / Excel)
- หลังจากนั้น **ใช้งานออฟไลน์ได้ครบ**: เปิดแอป · นำเข้า PDF · วาด / Point / ถอดปริมาณ · Export PDF / Excel / เบิกงวด
- ติดตั้งเป็นแอป: Android (Chrome) เมนู ⋮ → ติดตั้งแอป · iPhone (Safari) แชร์ → เพิ่มไปยังหน้าจอโฮม
- มีเน็ตเมื่อไหร่ แอปอัปเดตเป็นเวอร์ชันล่าสุดเอง

### 2) DrawNote_Offline.html — ไฟล์เดียว ไม่ต้องใช้เน็ตเลย
- ดับเบิลคลิกเปิดใน Chrome / Edge บนคอม ใช้ได้ทันทีแม้ไม่เคยต่อเน็ต
- ข้อมูลเก็บในเบราว์เซอร์ของเครื่องนั้น (คนละที่กับเวอร์ชันเว็บ) — ย้ายงานด้วย 📂 งานที่บันทึกไว้ → ส่งออก / นำเข้าไฟล์งาน (.json)

## หมายเหตุ
- ข้อมูลทั้งหมดอยู่ในเครื่อง ไม่ขึ้นเซิร์ฟเวอร์ → แนะนำ Backup (.json) เป็นประจำ
- ขณะออฟไลน์จะมีป้าย "📴 ออฟไลน์" ด้านบน — ทำงานต่อได้ปกติ
- ฟอนต์หน้าจอ Sarabun โหลดจาก Google ครั้งแรกที่มีเน็ต (ถ้ายังไม่เคยโหลดจะใช้ฟอนต์เครื่องแทน) — ฟอนต์ใน Report (TH Sarabun New) ฝังในแอปแล้ว

## ☁️ ส่งไฟล์ขึ้น Google Drive (ใหม่)
- ⚙ ตั้งค่า Report → กล่อง "ข้อมูล & พื้นที่ · Google Drive" → **☁️ เชื่อมต่อ Google Drive** → ทำตามขั้นตอนในหน้าต่าง (สร้าง OAuth Client ID ครั้งเดียว)
- Authorized JavaScript origins = ลิงก์ Vercel ของคุณ เช่น https://drawnote.vercel.app
- หลังเชื่อมต่อ ทุกครั้งที่ Export / Backup จะมีปุ่ม **Google Drive** → ไฟล์ไปอยู่ที่ Drive › DrawNote › ชื่อโครงการ
- ต้องต่อเน็ต และต้องเปิดผ่านเว็บ (ไฟล์ Offline.html ใช้ส่ง Drive ไม่ได้)
