# DrawNote (PWA)

## Deploy (Vercel)
1. สร้าง GitHub repo ใหม่ เช่น `drawnote` แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น root ของ repo
2. Vercel → Add New Project → เลือก repo → Framework: **Other** → Deploy (ไม่ต้องตั้งค่า build)

## ติดตั้งเป็นแอป
- **Android (Chrome):** เปิดลิงก์ Vercel → เมนู ⋮ → "ติดตั้งแอป / Add to Home screen"
  - หลังติดตั้ง: ใน LINE เปิดรูปหรือไฟล์ PDF → แชร์ → เลือก **DrawNote** → เลือกว่าจะ "สร้าง Point ใหม่ / แนบเข้า Point / เพิ่มเป็นแบบ"
- **iPhone / iPad (Safari):** ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"
  - iOS ไม่อนุญาตให้เว็บแอปรับไฟล์จากเมนูแชร์ ให้ใช้: ใน LINE กดค้างที่รูป → คัดลอก → ใน DrawNote กด **📋 วางรูป**
  - หรือใน LINE เปิดไฟล์ → แชร์ → "บันทึกไปยังไฟล์" → ใน DrawNote กด อัปโหลดแบบ / เพิ่มรูป เลือกจาก Files
- **คอมพิวเตอร์:** ลากไฟล์จาก LINE PC มาวางบนแบบ หรือคัดลอกรูปแล้วกด Ctrl+V

ใช้งาน Offline ได้หลังเปิดครั้งแรก ข้อมูลเก็บในเครื่อง — ใช้ "📂 งานที่บันทึกไว้ → ส่งออกไฟล์งาน" เพื่อย้ายเครื่อง
